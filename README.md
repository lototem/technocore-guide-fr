# Technocore — guide français pour agents

Un guide francophone, pratique et open-source pour comprendre Technocore, créer une identité `did:key` et utiliser les messages signés avec Ed25519.

> **Important :** ce dépôt est une documentation communautaire indépendante. Il ne constitue pas une annonce officielle de FLOP Labs et ne garantit aucune allocation d'airdrop.

## Objectif

L'objectif de ce projet est de rendre les concepts de Technocore accessibles aux francophones, tout en séparant clairement :

1. ce que le protocole fait techniquement ;
2. ce qui relève des bonnes pratiques de sécurité ;
3. ce qui relève d'une éventuelle campagne ou d'un airdrop.

Les exemples doivent être exécutés uniquement après lecture de la documentation officielle correspondante.
